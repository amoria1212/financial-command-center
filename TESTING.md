# Testing Guide - Financial Command Center

## Quick Test (Phase 1)

### Step 1: Create a Test Screenshot

**Option A: Use the Test HTML File**
1. Open `tests/sample_data/test-bank-statement.html` in your browser
2. Take a screenshot (Windows: Win + Shift + S)
3. Save to `data/screenshots/test-bank-statement.png`

**Option B: Use Your Own Financial Screenshot**
1. Log into any financial platform (bank, Quicken Simplifi, QuickBooks)
2. Take a screenshot showing account balances, dates, amounts
3. Save to `data/screenshots/` folder

### Step 2: Run the OCR Tool

```bash
# Process your screenshot
node src/main.js data/screenshots/test-bank-statement.png

# Or use npm
npm start data/screenshots/test-bank-statement.png
```

### Step 3: Review the Output

The tool will display:
- ✓ Confidence score (how accurate the OCR was)
- ✓ Currency amounts found
- ✓ Dates found
- ✓ Account numbers found
- ✓ Percentages found
- ✓ Raw text extracted

**Extracted data is saved to:** `data/extracted/[filename]_extracted.json`

## Troubleshooting

### Low Confidence Score (<70%)

**Cause:** Image quality issues (blurry, low resolution, poor contrast)

**Solutions:**
1. Retake screenshot at higher resolution
2. Ensure text is clearly visible
3. Avoid screenshots with busy backgrounds

### Missing Financial Data

**Cause:** OCR couldn't recognize numbers or formatting

**Solutions:**
1. Check if amounts have clear $ signs
2. Ensure dates are in standard format
3. Try preprocessing (it's on by default)

### Installation Issues

If you get errors about missing dependencies:

```bash
# Reinstall dependencies
npm install

# Verify Node.js version (needs v18+)
node --version
```
